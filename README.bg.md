# BalkanBench 🦉

**Отворен бенчмарк за *разбиране* на езиците на Балканите и Югоизточна Европа — не за скорост.**

Повечето бенчмаркове за LLM измерват ефективността и уменията, фокусирани върху английския език. **BalkanBench измерва нещо друго:** дали един модел наистина *разбира* тези езици — двусмислите, хомонимите, азбуките, диалектите, културата — и дали е **честен** (признава какво не знае), вместо да измисля факти.

> Flagship example: **„Горе горе горе горе него доле."** — four times *gore*, four meanings:
> *up · forests/mountains · [they] burn · worse.* → "Up above, the forests burn worse than below."
> Модел, който разреши това, е *разбрал* езика, а не просто го е превел.

Той изпълнява **13 оси × 12 езика = 156 детерминистични теста** за всеки модел. Без API ключове, без LLM-съдия — оценяването се базира на скрипт/ключова дума/число, така че всеки може да го възпроизведе.

---

## 12-те езика
Сръбски (sr), Хърватски (hr), Босненски (bs), Македонски (mk), Словенски (sl), Албански (sq),
Черногорски (cnr), Български (bg), Гръцки (el), Турски (tr), Румънски (ro), Унгарски (hu).

Осъзнаването на азбуката е вградено: **Azbuka** (Кирилица ≠ „просто кирилица“), Latinica и гръцки се
проверяват за всеки отговор — модел, който отговаря на македонски с латиница, губи точката за азбука.

## 13-те оси (какво се тества)

| Ос | Какво измерва |
|---|---|
| **FACT** | Реални познания по балканска история, култура, география |
| **HALLU** | Измислено лице/произведение/събитие → **признава ли „не знам“**, вместо да фабрикира? |
| **DETAIL** | Реална единица + измислен детайл → отбелязва ли несигурността? |
| **GRADED** | Нива на честност: показва частични познания (реалната единица) **и** отказва измисления детайл |
| **TEACH** | Преподаване/обясняване на тема **на целевия език** |
| **REASON** | Ежедневно разсъждение и извод |
| **LOGIC** | Кратка математика/логика — правилен ли е крайният резултат? |
| **LOGIC2** | Втори логически елемент (стабилност) |
| **ANALYSIS** | По-дълъг анализ — правилен резултат **и** видим стъпка-по-стъпка път |
| **INSTRUCT** | Следване на ограничения за форматиране / инструкции |
| **LONGFORM** | Кохерентен дълъг текст, на езика |
| **SEARCH** | Използване на инструменти: когато е несигурен, **извиква ли `web_search`**? |
| **TOOLBASE** | Дискриминация на инструменти: за базови познания, отговаря **директно** (не извиква инструмент) |

Всеки отговор се проверява и за **изход на целевия език / правилната азбука** — мислене и отговаряне
на целевия език, без преминаване през английски.

## Как работи оценяването (детерминистично)
Всяка ос използва фиксирана проверка — без субективно съдене:
- `name` / `num` — правилният факт/число се появява в отговора
- `idk` — появява се маркер за честност (*„не знам / не мога да потвърдя“*, според езика)
- `graded` — и реалната единица, **и** маркерът за честност се появяват
- `script` / `lang` — изходът е в очакваната азбука и език
- `calc` / `calc_long` — крайното число съвпада (дългият формат изисква и междинни стъпки)
- `search` — моделът е задействал инструмента `web_search`; `notool` — е отговорил без него

Общо: **/156**. Напълно възпроизводимо.

## Бърз старт — тествайте ваш собствен модел

BalkanBench комуникира с всеки модел, обслужван от **[Ollama](https://ollama.com)**.

```bash
# 1) Serve your model(s) with Ollama
ollama pull olivilo/zora          # or your own model, e.g. ollama pull gemma2:9b

# 2) Run the benchmark (Ollama endpoint defaults to localhost:11434)
python3 matrix_ollama.py --models "olivilo/zora,gemma2:9b,qwen2.5:7b"
```

Резултат: **таблица с резултати по оси** за всеки модел, `/156`, плюс детайли за всеки отговор.
Сравнете всеки модел — вашия fine-tune, базов модел, конкурент — върху едни и същи 156 задачи.

```
===== olivilo/zora =====
FACT 7/12  HALLU 10/12  DETAIL 8/12  GRADED 6/12  TEACH 12/12 ...
>>> olivilo/zora: 84/156
```

Не е необходим GPU за самия инструмент — Ollama стартира модела, бенчмаркът просто оценява.

## Философия
> Модел за Балканите трябва да разбира тези езици **отвътре** — техните двойни
> значения, диалекти, азбуки и култура — и да бъде **честен** за своите ограничения. Скоростта е второстепенна.
> **Разбирането е важно.**
