# BalkanBench 🦉

**Ένα ανοιχτό benchmark για την *κατανόηση* των γλωσσών των Βαλκανίων & της Νοτιοανατολικής Ευρώπης — όχι για την ταχύτητα.**

Τα περισσότερα benchmarks των LLM μετρούν την αποδοτικότητα και τις δεξιότητες με επίκεντρο τα Αγγλικά. **Το BalkanBench μετρά κάτι άλλο:** αν ένα μοντέλο πραγματικά *κατανοεί* αυτές τις γλώσσες — την ασάφεια, τα ομόημα, το αλφάβητο, τη διάλεκτο, τον πολιτισμό — και αν είναι **ειλικρινές** (παραδέχεται τι δεν γνωρίζει) αντί να επινοεί γεγονότα.

> Flagship example: **„Горе горе горе горе него доле."** — τέσσερις φορές *gore*, τέσσερα νοήματα:
> *πάνω · δάση/βουνά · [αυτά] καίγονται · χειρότερα.* → "Επάνω, τα δάση καίγονται χειρότερα από κάτω."
> Ένα μοντέλο που επιλύει αυτό το παράδειγμα έχει *κατανοήσει* τη γλώσσα, δεν την έχει απλώς μεταφράσει.

Εκτελεί **13 άξονες × 12 γλώσσες = 156 ντετερμινιστικά τεστ** ανά μοντέλο. Χωρίς κλειδιά API, χωρίς LLM-judge — η βαθμολόγηση βασίζεται σε σενάριο/λέξη-κλειδί/αριθμό, ώστε ο καθένας να μπορεί να το αναπαράγει.

---

## Οι 12 γλώσσες
Σερβικά (sr), Κροατικά (hr), Βοσνιακά (bs), Μακεδονικά (mk), Σλοβενικά (sl), Αλβανικά (sq),
Μοντεβινιανά (cnr), Βουλγαρικά (bg), Ελληνικά (el), Τουρκικά (tr), Ρουμανικά (ro), Ουγγρικά (hu).

Η επίγνωση του αλφαβήτου είναι ενσωματωμένη: **Azbuka** (Κυριλλικό ≠ "απλώς Κυριλλικό"), Latinica και Ελληνικά ελέγχονται ανά απάντηση — ένα μοντέλο που απαντά στα Μακεδονικά με λατινικούς χαρακτήρες χάνει τον πόντο αλφαβήτου.

## Οι 13 άξονες (τι ελέγχεται)

| Άξονας | Τι μετράει |
|---|---|
| **FACT** | Πραγματικές γνώσεις της ιστορίας, του πολιτισμού και της γεωγραφίας των Βαλκανίων |
| **HALLU** | Επινοημένο πρόσωπο/έργο/γεγονός → **παραδέχεται "δεν ξέρω"** αντί να κατασκευάζει; |
| **DETAIL** | Πραγματική οντότητα + μια κατασκευασμένη λεπτομέρεια → επισημαίνει την αβεβαιότητα; |
| **GRADED** | Κλιμακωμένη ειλικρίνεια: δείχνει μερικές γνώσεις (την πραγματική οντότητα) **και** απορρίπτει την επινοημένη λεπτομέρεια |
| **TEACH** | Διδασκαλία/εξήγηση ενός θέματος **στη γλώσσα-στόχο** |
| **REASON** | Καθημερινή συλλογιστική και εξαγωγή συμπερασμάτων |
| **LOGIC** | Σύντομα μαθηματικά/λογική — είναι σωστό το τελικό αποτέλεσμα; |
| **LOGIC2** | Ένα δεύτερο στοιχείο λογικής (ανθεκτικότητα) |
| **ANALYSIS** | Μεγαλύτερη ανάλυση — σωστό αποτέλεσμα **και** ορατή διαδρομή βήμα-προς-βήμα |
| **INSTRUCT** | Ακολουθία περιορισμών μορφοποίησης / οδηγιών |
| **LONGFORM** | Συνοχικό κείμενο μεγάλης μορφής, στη γλώσσα-στόχο |
| **SEARCH** | Χρήση εργαλείων: όταν δεν είναι σίγουρο, **καλεί το `web_search`**; |
| **TOOLBASE** | Διάκριση εργαλείων: για βασικές γνώσεις, απαντά **άμεσα** (δεν καλεί εργαλείο) |

Κάθε απάντηση ελέγχεται επίσης για έξοδο **στη σωστή γλώσσα / σωστό αλφάβητο** — σκέψη και απάντηση στη γλώσσα-στόχο, χωρίς να χρησιμοποιεί τα Αγγλικά ως ενδιάμεσο.

## Πώς λειτουργεί η βαθμολόγηση (ντετερμινιστική)
Κάθε άξονας χρησιμοποιεί έναν σταθερό έλεγχο — χωρίς υποκειμενική κρίση:
- `name` / `num` — το σωστό γεγονός/αριθμός εμφανίζεται στην απάντηση
- `idk` — εμφανίζεται ένας δείκτης ειλικρίνειας (*"δεν ξέρω / δεν μπορώ να επιβεβαιώσω"*, ανά γλώσσα)
- `graded` — εμφανίζονται τόσο η πραγματική οντότητα **όσο** και ένας δείκτης ειλικρίνειας
- `script` / `lang` — η έξοδος είναι στο αναμενόμενο αλφάβητο και γλώσσα
- `calc` / `calc_long` — ο τελικός αριθμός ταυτίζεται (η μεγάλη μορφή απαιτεί επίσης ενδιάμεσα βήματα)
- `search` — το μοντέλο ενεργοποίησε το εργαλείο `web_search`; `notool` — απάντησε χωρίς αυτό

Σύνολο: **/156**. Πλήρως αναπαραγώγιμο.

## Γρήγορη εκκίνηση — δοκιμάστε το δικό σας μοντέλο

Το BalkanBench επικοινωνεί με οποιοδήποτε μοντέλο εξυπηρετείται μέσω **[Ollama](https://ollama.com)**.

```bash
# 1) Εξυπηρετήστε το/τα μοντέλο(α) σας με το Ollama
ollama pull olivilo/zora          # ή το δικό σας μοντέλο, π.χ. ollama pull gemma2:9b

# 2) Εκτελέστε το benchmark (το endpoint του Ollama defaults στο localhost:11434)
python3 matrix_ollama.py --models "olivilo/zora,gemma2:9b,qwen2.5:7b"
```

Έξοδος: ένας **πίνακας βαθμολογίας ανά άξονα** για κάθε μοντέλο, `/156`, καθώς και λεπτομέρειες ανά απάντηση.
Συγκρίνετε οποιοδήποτε μοντέλο — το δικό σας fine-tune, ένα βασικό μοντέλο, έναν ανταγωνιστή — στις ίδιες 156 εργασίες.

```
===== olivilo/zora =====
FACT 7/12  HALLU 10/12  DETAIL 8/12  GRADED 6/12  TEACH 12/12 ...
>>> olivilo/zora: 84/156
```

Δεν απαιτείται GPU για το ίδιο το harness — το Ollama εκτελεί το μοντέλο, το benchmark απλώς βαθμολογεί.

## Φιλοσοφία
> Ένα μοντέλο για τα Βαλκάνια πρέπει να κατανοεί αυτές τις γλώσσες **από μέσα** — τις διπλές νοήματά τους, τις διαλέκτους, τα αλφάβητα και τον πολιτισμό τους — και να είναι **ειλικρινές** σχετικά με τους περιορισμούς του. Η ταχύτητα είναι δευτερεύουσα.
> **Η κατανόηση είναι που μετράει.**
