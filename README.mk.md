# BalkanBench 🦉

**Отворен бенчмарк за *разбирање* на јазиците на Балканот и Југоисточна Европа — не за брзина.**

Повеќето LLM бенчмаркови ја мерат ефикасноста и вештините фокусирани на англискиот јазик. **BalkanBench мери нешто друго:** дали моделот навистина ги *разбира* овие јазици — двосмислоста, хомонимите, писмото, дијалектот, културата — и дали е **искрен** (признава што не знае) наместо да измислува факти.

> Flagship example: **„Горе горе горе горе него доле."** — four times *gore*, four meanings:
> *up · forests/mountains · [they] burn · worse.* → "Up above, the forests burn worse than below."
> Модел кој ќе го реши ова, го *разбрал* јазикот, а не само го превел.

Извршува **13 оси × 12 јазици = 156 детерминистички тестови** по модел. Без API клучеви, без LLM-судија — бодувањето се базира на скрипта/клучни зборови/броеви, па секој може да го репродуцира.

## 12-те јазици
Српски (sr), Хрватски (hr), Босански (bs), Македонски (mk), Словечки (sl), Албански (sq),
Црногорски (cnr), Бугарски (bg), Грчки (el), Турски (tr), Ромуњски (ro), Угарски (hu).

Свесноста за писмото е вградена: **Azbuka** (Кирилица ≠ „само кирилица“), Латиница и Грчки се
проверуваат по одговор — модел кој одговара на македонски со латично писмо го губи бодот за писмото.

## 13-те оси (што се тестира)

| Оса | Што мери |
|---|---|
| **FACT** | Вистинско знаење за балканската историја, култура, географија |
| **HALLU** | Измислена личност/дело/настан → дали **признава „не знам“** наместо да фабрикира? |
| **DETAIL** | Вистински ентитет + измислен детаљ → дали ја означува несигурноста? |
| **GRADED** | Градирана искреност: покажува делумно знаење (вистинскиот ентитет) **и** го одбива измислениот детаљ |
| **TEACH** | Подريسнување/објаснување на тема **на целниот јазик** |
| **REASON** | Секојдневно размислување и заклучување |
| **LOGIC** | Кратка математика/логика — дали конечниот резултат е точен? |
| **LOGIC2** | Втора логичка ставка (робусност) |
| **ANALYSIS** | Подолга анализа — точен резултат **и** видлив чекор-по-чекор пат |
| **INSTRUCT** | Следење на ограничувањата за форматирање / инструкциите |
| **LONGFORM** | Кохерентен текст во долга форма, на јазикот |
| **SEARCH** | Користење алатки: кога не е сигурен, дали **повикува `web_search`**? |
| **TOOLBASE** | Дискриминација на алатки: за основно знаење, одговара **директно** (не повикува алатка) |

Секој одговор е исто така проверен за **излез на целниот јазик / точно писмо** — размислување и одговарање на целниот јазик, без префрлање преку англиски.

## Како функционира бодувањето (детерминистички)
Секоја оса користи фиксна проверка — без субјективно судење:
- `name` / `num` — точниот факт/број се појавува во одговорот
- `idk` — маркер за искреност (*„не знам / не можам да потврдам“*, за секој јазик) се појавува
- `graded` — вистинскиот ентитет **и** маркерот за искреност се појавуваат
- `script` / `lang` — излезот е во очекуваното писмо и јазик
- `calc` / `calc_long` — конечниот број се совпаѓа (долгата форма бара и меѓуопови)
- `search` — моделот ја активираше алатката `web_search`; `notool` — одговори без неа

Вкупно: **/156**. Целосно репродуцибилно.

## Брз старт — тестирајте го вашиот модел

BalkanBench комуницира со секој модел сервиран преку **[Ollama](https://ollama.com)**.

```bash
# 1) Serve your model(s) with Ollama
ollama pull olivilo/zora          # or your own model, e.g. ollama pull gemma2:9b

# 2) Run the benchmark (Ollama endpoint defaults to localhost:11434)
python3 matrix_ollama.py --models "olivilo/zora,gemma2:9b,qwen2.5:7b"
```

Излез: **табела со поени по оса** за секој модел, `/156`, плус детали по одговор.
Споредете го кој било модел — вашиот fine-tune, базен модел, конкурент — на истите 156 задачи.

```
===== olivilo/zora =====
FACT 7/12  HALLU 10/12  DETAIL 8/12  GRADED 6/12  TEACH 12/12 ...
>>> olivilo/zora: 84/156
```

Не е потребен GPU за самиот harness — Ollama го пушта моделот, бенчмаркот само бодува.

## Филозофија

> **Разбирањето е важно.**
